## 二、关键实现（摘要）

### 1. 静态目录

```python
root = os.path.realpath(STATIC_DIR)
safe = unquote(relative, errors="strict").replace("\\", "/")   # 只解码一次
if not safe: safe = "index.html"
invalid = ("\x00" in safe or safe.startswith("/")
           or bool(ntpath.splitdrive(safe)[0]) or os.path.isabs(safe))
if invalid: -> 400
path = os.path.realpath(os.path.join(root, safe))
try:    contained = os.path.commonpath([root, path]) == root
except ValueError:  contained = False      # 跨盘符
if not contained: -> 400
```

### 2. 请求入口

* Host：唯一；`_parse_host` 支持 `[::1]:port`；`ipaddress.is_loopback`；端口必须等于 `self.server.server_address[1]`。
* Origin：存在时 `scheme==http`、无 userinfo/路径/查询/fragment、hostname 与 Host 一致、端口一致；`null`/多值 403。
* `Sec-Fetch-Site`：只允许 `same-origin` / `none`。
* POST：拒绝 `Transfer-Encoding`；`Content-Length` 必须 digits 且 ≤ 1 MiB（超限在读 body 前 413）；
  有 body 时 media type 必须是 `application/json`（否则 415）；非法 JSON / 非对象 → 400。

### 3. 登录脱敏

* 异常文本：`QR response missing qr/lp`、`login response has no location`、`login response has no ssecurity`、
  `login response carried no serviceToken`、`QR request failed: code=%s`、`QR poll failed: code=%s`。
* `_safe_reason()`：只输出 `connection refused` / `timeout` / `dns failure` / `connection reset` / `network unreachable`。
* `LoginFlow._run()`：`LoginTimeout` → 「扫码登录超时，请重试」，其它 → 「<类型>: 登录失败（详情见日志）」，日志只记类型。
* `repr(Credentials)` → `<Credentials user=… authenticated=True|False>`。

## 四、修复前 / 修复后的对照

* 静态：修复前，`os.path.join(root, 'C:/x')` 返回 `'C:/x'`（root 被丢弃），因此 `GET /static/C:/Windows/win.ini` 可读任意文件；
  修复后同类请求返回 400。**说明**：0.7.26 上我没有留下列用 200 的截图，这一条是依据 `os.path.join` 的实测行为 + 评审独立确认。
* 请求来源：修复前任何 Host/Origin 都能调 `/api/*`；修复后外域 Host / 跨源 Origin / 跨站 Fetch Metadata 一律 403。
* 登录：修复前 `LoginFlow.message` 直接拼接 `str(exc)`；修复后只保留异常类型。

## 五、仍存在的限制（未完成项）

1. **未做浏览器端到端 DNS rebinding 验证**：需要可控 DNS + 真实浏览器环境，本轮只做了服务端校验与单元级攻击请求。
2. **未加启动随机令牌**：评审意见中列为「后续纵深防御」，本轮未实现，前端也未改。
3. **空 body 的 POST 不强制 Content-Type**：`Content-Length: 0` 且无 body 时允许（如 `curl -X POST /api/messages/read`），
   有 body 时必须 `application/json`。如果要求「所有 POST 无论有无 body 都必须带 JSON 类型」，我可以再收紧。
4. `Sec-Fetch-Site` 缺失时放行（老浏览器/CLI），仅靠 Host + Origin 兜底。
